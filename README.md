# Celestial Site Builder

Crie um site moderno e profissional usando exclusivamente as informações que vou colar abaixo (copiadas do Google Maps da empresa).

Requisitos:

- Extraia automaticamente nome, descrição, avaliações, endereço, telefone, horário de funcionamento, fotos, serviços e qualquer outra informação disponível.

- Gere uma landing page completa e responsiva.

- Design moderno, com animações suaves, cores baseadas na identidade da empresa e aparência premium.

- Crie as seções: Hero, Sobre, Serviços, Galeria, Avaliações, Localização (Google Maps), Horários, Contato e FAQ.

- Se alguma informação estiver faltando, não invente. Apenas omita a seção ou use um texto indicando que a informação não foi fornecida.

- Utilize as avaliações para destacar os principais pontos positivos dos clientes.

- Adicione botões para WhatsApp, ligar e traçar rota no Google Maps quando essas informações existirem.

- Otimize o site para SEO.

- Gere um código limpo, organizado e pronto para publicação.
